# AI Research Agent

A beginner-friendly AI research agent built with CrewAI, Groq, DuckDuckGo and Streamlit.

## Features

- Single autonomous research agent
- DuckDuckGo web search
- Groq GPT-OSS 120B
- Structured research reports
- Source URLs
- Markdown report download
- Streamlit interface

## Tech Stack

- Python 3.12
- Streamlit
- CrewAI
- Groq
- LiteLLM
- DuckDuckGo / DDGS

## How It Works

1. User enters a research topic.
2. CrewAI creates a research task.
3. The research agent searches the web.
4. The agent analyzes the search results.
5. The agent creates a structured report.
6. The report is displayed in Streamlit.
